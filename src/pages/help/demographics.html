Overview

The Demographics Tool displays configurable bar charts of crude or age-adjusted cancer mortality rates. Use it to compare population groups within one plot or across a set of plot panels.

Tutorial: Compare mortality rates by race and ethnicity

In this example, you will compare 2024 age-adjusted lung and bronchus cancer mortality rates across racial and ethnic groups in the United States.

What you will learn

  • How Within Plot and Between Plot shape the chart.
  • How to refine a question with the selection controls.
  • How to inspect, filter, and download results.

  1. Open the Demographics Tool

    Select Open the Demographics Tool above. The chart initially loads with a comparison by race and ethnicity.

  2. Set up the comparison

    Under Compare, select Race/Ethnicity for Within Plot and None for Between Plot. Each racial or ethnic group will appear as a separate bar in one chart.

    If you choose a field for Between Plot, NIH-MERGE creates a separate panel for each value of that field. A field cannot be used for both comparison controls at the same time.

  3. Choose the population and cancer site

    Under Select, use these values:

    Year
    2024
    US State
    All
    Cancer Site
    Lung and Bronchus
    Sex
    All
    Age Group
    All

    The Race/Ethnicity selection is unavailable because that field is being used to compare groups in the chart.

  4. Choose the measure

    Under Other, select Age-Adjusted Cancer Mortality (per 100,000). Age-adjusted rates are useful for comparing populations with different age distributions.

    If you select or compare age groups, the tool automatically uses the crude mortality rate.

  5. Read and refine the chart

    Compare bar heights to see how displayed rates differ. Point to a bar for its value. Use Filter to show or hide comparison groups, and use Graph Settings to display confidence intervals or suppressed categories.

  6. Review or download the results

    Select Data Table to inspect the values behind the chart. Select Download to save the data or figure.

Interpret results

Rates based on small numbers may be suppressed. Treat visible differences as descriptive; this chart alone does not establish whether differences are statistically significant or explain why they occur.

Additional guidance about confidence intervals, age adjustment, and comparisons will be added here.

Downloads

Data can be downloaded as CSV, TSV, or JSON. Figures can be saved as PNG or SVG. The Data Table provides an accessible view of the values behind the chart.
